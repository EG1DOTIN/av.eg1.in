Automated Setup

Quick Install (One-Liners)

Want a fast, automated setup without manual steps? Run a single one-liner command to provision Python, configure an isolated virtual environment, check ClamAV, and set up desktop launchers automatically.

Windows (PowerShell 1-Liner)
PowerShell
powershell -ExecutionPolicy Bypass -Command "Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/EG1DOTIN/pyEGClamUI/main/setup/install.ps1' -OutFile setup.ps1; .\setup.ps1"

Automated bootstrap setup provisions Python, creates an isolated virtual environment (.venv), checks ClamAV binaries, and configures desktop shortcuts automatically.

Linux (Bash 1-Liner)
Universal Bash
curl -sSL https://raw.githubusercontent.com/EG1DOTIN/pyEGClamUI/main/setup/install.sh | bash

Provisions isolated virtual environment, checks ClamAV daemon (clamd), installs dependencies, and creates system application menu entries with icons.

macOS (Terminal 1-Liner)
Universal Bash
curl -sSL https://raw.githubusercontent.com/EG1DOTIN/pyEGClamUI/main/setup/install.sh | bash

Supports Apple Silicon (M-series) and Intel architectures, configures environment paths, and integrates with the top Menu Bar.

Python Pip (Cross-Platform)
Universal PyPI
pip install pyegclamui

Install directly from PyPI into your active Python environment. Launch anytime with pyegclamui or short alias egclam.

Developer & Manual Setup

Step-by-Step Package Managers

For developers, package maintainers, and custom deployments. Follow the manual workflow below: first install the ClamAV engine prerequisite, then install pyEGClamUI.

Step 1 (Prerequisite): ClamAV Antivirus Engine

The desktop GUI operates alongside the open-source ClamAV engine. For step-by-step developer setup, ensure ClamAV is installed on your system using the commands in the tabs below before running pyEGClamUI.

Windows 10 / 11 Installation

Supports 64-bit Windows 10 and Windows 11 with native dark titlebar

64-bit
1. Install ClamAV Engine (via Windows Package Manager)
winget install Cisco.ClamAV
2. Install via Python pip
pip install pyegclamui
3. Launch the Application
pyegclamui

You can also use the short alias: egclam

Linux Installation

Supports Ubuntu, Debian, Fedora, Arch Linux, and openSUSE

Universal
Ubuntu / Debian / Linux Mint
sudo apt update && sudo apt install -y clamav clamav-daemon && pip install pyegclamui
Fedora / RHEL / CentOS
sudo dnf install -y clamav clamd clamav-update && pip install pyegclamui
Arch Linux / Manjaro
sudo pacman -S clamav && pip install pyegclamui

macOS Installation

Supports macOS 12+ (Apple Silicon & Intel x86_64)

Universal
1. Install ClamAV via Homebrew
brew install clamav
2. Install via Pip
pip install pyegclamui

Build from Source

Clone the official GitHub repository for local development

Open Source
git clone https://github.com/EG1DOTIN/pyEGClamUI.git && cd pyEGClamUI && pip install -e .
