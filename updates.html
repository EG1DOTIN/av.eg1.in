Updates & Release History

pyEGClamUI v3.1.0

Latest Release
Released: October 2026 • Performance & Non-Blocking GUI Suite
View on GitHub →

Key Highlights in v3.1.0:

  • Native Inno Setup Windows Suite: Standalone installer (pyEGClamUI.exe) with bundled Python 3.12 embedded runtime, automated ClamAV provisioning, and self-elevating ClamD service activator.
  • Centric Hidden Process Foundation: Eliminates all console window pops and command-prompt flashing across scans, updates, and engine commands using CREATE_NO_WINDOW.
  • Non-Blocking Asynchronous GUI Lifecycle: Offloads heavy engine audits and health checks to background worker threads (StatusRefreshWorker), permanently eliminating UI titlebar freezes.
  • In-Memory TTL Caching: Instant tab switching via 6-second caching in engine detector and 0.5s socket connect timeouts.
  • Automated Multi-OS CI/CD Pipelines: GitHub Actions packaging workflows for Windows, Linux, and macOS with 125/125 passing automated unit & regression tests.

pyEGClamUI v3.0.0

Release
Released: September 2026 • Initial Production Release
View on GitHub →

Key Highlights in v3.0.0:

  • Cross-Platform: Runs natively on Windows 10/11, Linux, and macOS.
  • Engine Auto-Discovery: Automatically detects clamscan, clamd, and freshclam across system PATH and standard directories.
  • ClamAV Daemon Integration: Communicates via Unix domain socket or TCP socket using standard INSTREAM chunk framing.
  • Multiple Scan Modes: Quick scan, full system scan, custom folder scan, and memory scan for active processes.
  • Live Progress Tracking: Displays real-time file counters, active scanning paths, elapsed time, and threat notifications.
  • Isolated Quarantine Vault: Isolates detected files with unique IDs, SHA-256 hashes, and non-executable .quarantine extensions, with one-click restoration.
  • Debounced Real-Time Guard: Monitors Downloads and Desktop folders using watchdog with a debounce queue to avoid locking files during writes.
  • Desktop & Menu Integration: Integrates with Linux application menus (XDG), macOS Menu Bar, and Windows System Tray.
  • FreshClam Updates: Check and update ClamAV virus signatures directly from the UI without requiring elevated permissions.
  • Dark Theme: Clean vector icons with native dark titlebar frame integration (Windows DWM, Linux GTK, and macOS).
  • Lightweight & Privacy-Focused: Zero telemetry, zero tracking, no network beacons, and 100% free and open-source (GPL-3.0).

Automated Multi-Platform CI/CD Packaging Pipeline

Packaging
September 2026 • GitHub Actions Build Automation

Established automated GitHub Actions CI/CD workflows to compile, package, and release signed native executables and checksums for all major desktop platforms:

  • Windows 10 / 11: Standalone executable installer and portable ZIP packages.
  • Linux: Universal AppImage and portable tarballs compatible across Ubuntu, Debian, Fedora, Arch, and Linux Mint.
  • macOS: Universal DMG image natively supporting Apple Silicon (M1/M2/M3/M4) and Intel x86_64 architectures.

Previous Versions Deprecated

All previous projects and repositories—including EGClamNetAntivirus and EG-ClamNet-Antivirus-2—are deprecated, unsupported, not maintained and permanently removed from GitHub and version history.

If you are using older version, please migrate to pyEGClamUI   latest version, which replaces all previous iterations with a stable and production-ready cross-platform codebase.
