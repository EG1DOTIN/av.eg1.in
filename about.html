Project Background & Mission

pyEGClamUI provides a native, responsive graphical user interface for ClamAV, for running scans, managing isolated threats, and updating virus definition databases across Windows, Linux, and macOS—without adding commercial bloatware, advertisements, or background tracking.

The project is independently maintained and published by EG1 (eg1.in) under the GNU General Public License v3.0 (GPL-3.0). Both the desktop application and this website are fully open source.
