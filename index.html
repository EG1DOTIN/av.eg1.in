Desktop GUI for ClamAV

An open-source, cross-platform desktop graphical user interface for the ClamAV antivirus engine. Built with Python and PySide6 (Qt) for Windows, Linux, and macOS.

Core Capabilities

Visual Control & Core Capabilities

A clean desktop interface connecting you to the ClamAV engine with multiple scan modes, real-time folder monitoring, and quarantine isolation.

Engine Auto-Discovery

Automatically detects installed ClamAV binaries across standard system paths and communicates directly with the local scanning service for fast performance.

Auto-Detection Local Daemon CLI & GUI

Four Scan Profiles

Choose between a Quick Scan of high-priority system areas most prone to infection, a Full System Scan of all drives, Custom drag-and-drop file scanning, or Windows active process memory scanning.

Quick & Full Scan Process Memory Drag & Drop

Real-Time Folder Guard

Monitors up to two selected folders in real time (defaults to Downloads and Desktop, customizable in Settings) to inspect new files as they arrive.

Up to 2 Folders Custom Paths Background Guard

Quarantine Management

Detected files are securely moved to an isolated quarantine vault to prevent accidental execution, with options to safely restore or permanently delete them.

Safe Vault Review Threats 1-Click Restore

Bootstrap Installer

Quick Installation

Automated bootstrap setup commands that provision Python, configure an isolated environment, check ClamAV, and set up desktop launchers automatically.

Windows (PowerShell 1-Liner)
PowerShell
powershell -ExecutionPolicy Bypass -Command "Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/EG1DOTIN/pyEGClamUI/main/setup/install.ps1' -OutFile setup.ps1; .\setup.ps1"

Automated bootstrap setup provisions Python, creates an isolated virtual environment (.venv), checks ClamAV binaries, and configures desktop shortcuts automatically.

Linux (Bash 1-Liner)
Universal Bash
curl -sSL https://raw.githubusercontent.com/EG1DOTIN/pyEGClamUI/main/setup/install.sh | bash

Provisions isolated virtual environment, checks ClamAV daemon (clamd), installs dependencies, and creates system application menu entries with icons.

macOS (Terminal 1-Liner)
Universal Bash
curl -sSL https://raw.githubusercontent.com/EG1DOTIN/pyEGClamUI/main/setup/install.sh | bash

Supports Apple Silicon (M-series) and Intel architectures, configures environment paths, and integrates with the top Menu Bar.

Python Pip (Cross-Platform)
Universal PyPI
pip install pyegclamui

Install directly from PyPI into your active Python environment. Launch anytime with pyegclamui or short alias egclam.
